# CyberUI — 3.1 Premium UI Refresh

## What changed
- Refined the default Vaxorin palette for stronger contrast and a cleaner premium/cyber aesthetic.
- Increased the default canvas to 900×590 and added responsive sidebar sizing for smaller viewports.
- Added safer window dragging bounds so the interface is harder to lose off-screen.
- Added `/` to focus search and `Esc` to clear/release search focus.
- Improved button hover/press feedback with accent edge lighting.
- Improved input focus feedback with an animated accent border.
- Added clearer dropdown selection indicators and smoother option hover states.
- Reduced font-dependent control styling and strengthened window depth/shadow tokens.
- Preserved the existing public element APIs and configuration model.

## Compatibility
Existing `CreateWindow`, tabs, sections, elements, flags, configuration saving, themes, and handles remain compatible.
