# CyberUI 5.0 — Mega Update

- Added real Vaxorin / Classic / Minecraft whole-interface variants.
- Classic skin is a full-screen category menu inspired by the supplied Minecraft-style reference.
- Minecraft skin adds player headshot panel and hotbar-style slots.
- Added first-class Elements modules: Card, Badge, Progress, Status, Notice, Stat, Divider, IconButton.
- Footer avatar now falls back to the local player HeadShot thumbnail automatically.
- Layout switching is now an actual shell switch instead of a resize preset.
- Existing Vaxorin interface remains available as the default.
