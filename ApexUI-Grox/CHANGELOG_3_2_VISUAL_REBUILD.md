# CyberUI 3.2 — Visual Rebuild

This release intentionally changes the composition instead of only adding shadows or color tweaks.

## What changed
- 920x600 default canvas with a larger desktop-oriented workspace.
- 72px product header with stronger branding hierarchy.
- 202px workspace sidebar with denser, clearer navigation items.
- Navigation items now use a persistent surface, larger type, and a stronger active rail.
- Every tab now has a dedicated page header with eyebrow, title, and accent rule.
- Main content starts lower to create a real page hierarchy instead of cards beginning immediately.
- Updated Vaxorin palette: darker shell, cooler surfaces, purple-to-blue accent system.
- Increased card/control sizing and spacing for a more deliberate dashboard feel.
- Footer compressed so navigation gets more usable vertical space.
- Version metadata updated to 3.2.

## Compatibility
Public window/tab/section/element APIs were not intentionally renamed or removed.
